# Audrey Surya Portfolio

A frontend-only developer portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validate

```bash
npm run typecheck
npm run build
```

The portfolio uses local CSS project thumbnails and has no backend, datastore, authentication, or remote image dependency.
